Kiểm tra responsive dashboard DASHBOARD HIỆN TẠI

Chọn khung hoặc nhập kích thước vùng web. Đang xem các component của dashboard chính. Desktop rộng từ 1800 CSS px; bố cục màn rất rộng từ 2400 CSS px (cỡ chữ trình duyệt mặc định).

Đã áp dụng bố cục được duyệt cho viewport từ 2400 CSS px. Tất cả khung bên dưới dùng cùng code với /dashboard. Số inch và độ phân giải trong preset là giả định; có thể nhập kích thước thực tế.
1:1 để kiểm tra độ nét; chế độ thu nhỏ chỉ để xem bố cục.
Tính viewport từ độ phân giải màn hình (ước tính)

Số inch không quyết định viewport. Phần giao diện Chrome/taskbar phụ thuộc máy; 170px là giả định có thể sửa. Ô rộng/cao CSS phía trên mới là kích thước trang đang được kiểm tra.
